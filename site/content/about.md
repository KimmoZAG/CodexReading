# 关于本指南

这是一份面向工程师的 Codex 源码阅读指南，把 Codex 这个"让不可信模型安全替你干活"的项目，按进程、协议、配置、工具、前端等主线拆成一份可逐章钻进去的地图。它不是一个 API 文档，而是一本"陪你读代码"的书：每一章聚焦一条主线，告诉你该从哪个 crate / 哪个文件读起，行号会漂但名字不会，所以多用名字去搜。

怎么用这个站点：

- **左侧选章**：左侧目录列出全部章节，按阅读顺序排列，点一下即可跳转；当前章会高亮。
- **全文搜索**：按 `Ctrl`（Windows/Linux）或 `⌘`（macOS）加 `K`，弹出搜索框，对整个站点做全文检索，回车跳到命中处。
- **看快捷键**：按 `?` 弹出快捷键一览，所有键盘操作都在里面。
- **翻章**：用 `←` / `→`，或者 Vi 风格的 `j` / `k`，在上/下一章之间快速切换。
- **跳到源码**：正文中出现的 `path:line`（例如 `core/src/session/turn.rs:153`）是可点击引用，点一下直接跳到 GitHub 对应文件与行号，方便边读边对照。
- **深浅色切换**：右上角切换浅色 / 深色主题，刷新后也会记住你的选择。

## 阅读建议

章节按难度分了四档标签——**入门、进阶、深入、参考**。建议顺着这个梯度来，不要一上来就扎进最深的章：

1. **入门**：先读 `引子：Codex 到底是什么` 和 `第 1 章：仓库地形图`。这两章建立全局语感——Codex 由哪些进程组成、代码落在哪些 crate——是后面一切的地基，跳过它们会处处碰壁。
2. **进阶**：接着读第 2~9 章（进程模型、core 公共 API、主循环、工具、沙箱、TUI、协议、配置）。这一档讲"系统怎么跑起来"，先把驱动轴和主干流程吃透，再谈细节。
3. **深入**：第 11~30 章是真正的深水区——exec-server 执行链路、模型客户端、配置分层、Hooks、Skills、MCP、上下文压缩、插件、审批、异步运行时、构建与分发等。挑跟你目标相关的几章精读即可，不必一口气硬啃。
4. **参考**：`术语表`、`架构全景` 和 `收尾：阅读路线` 随时可查。读到陌生名词回去翻术语表，想看全貌回架构全景，读完主线后看收尾章规划下一步钻哪条线。

一句话：**先地图后主线，再按目标挑深入章，参考档常备案头**。
